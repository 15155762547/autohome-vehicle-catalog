# 汽车之家在售与预售目录重建执行清单

目标：Python + Scrapy + Pydantic；全中文、按spec独立列，试验Base三张新表；个人公开仓库autohome-vehicle-catalog。

授权：用户2026-10-17确认：在售＋预售；特斯拉明确四车系Model 3、Model Y、Model Y L、赛博越野旅行车；停售/未售排除；不按进口身份额外过滤；接受配置参数扩展表；公开仓库。旧两表仅改名带已弃用，保留记录/ID，生产只读，图片仅URL。

## 模块与验收

- [ ] models.py / parse.py：Pydantic验证响应身份/字段类型，按每份响应titleid映射参数；非全局列号；厂商不等于品牌；保存位置/选配/条件与原符号。不计算气囊总数。测试错series/spec、变动titleid、空itemname＋sublist、前后气囊、数值与缺失。
- [ ] spider.py / storage.py：Scrapy目录发现、配置清单、参数抓取。先按品牌目录、不是仅新能源搜索入口。scope识别在售与用户指定预售/页面明确预售；模糊未售进入审计。保存响应URL/时间/hash与失败，禁止图片二进制请求；外接盘缺失失败，遇限制暂停。测试停售/未知状态排除、特斯拉四车系、字段新增与限流。
- [ ] cli.py / export.py：采集、离线重放、独立列CSV；中文字典可审计增加字段。纯数字列用number，带符号条件保留原值；跨配置来源严格对应。测试字段缺失与新字段报告、不重复配置。
- [ ] feishu.py：显式shengxu/user，实验Base白名单；备份及revision检查→旧表改名→新三表→稳定键写入计划→小样本apply→逐字段回读。所有写入含回执；关联新表系统ID；无删除操作，不自动迁移旧i18n关联。测试生产目标拒绝、重复键与二次计划零变更。
- [ ] README / schema / public repo：不提交Cookie、凭据、飞书备份/业务ID或raw运行数据；锁依赖、复现命令和中文说明；本地测试、5车系/特斯拉小样本、并发1/2/4测量、字段与复跑核验后提交推送。

## 重要实际边界

源站品牌API把state10和0均归在“未售”，state10不能自动全算预售。特斯拉赛博越野旅行车按用户明确范围保留，其他模糊未售必须有明确预售证据或进入待复核清单。预售无价、无参数就留空，不为补数量编造。

所有缓存、日志、原始响应、飞书schema/records/回执位于仓库外的外接盘运行目录。公开仓库的schema只含源站通用字段，不含飞书记录和内部映射。
